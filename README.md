# Fiorente Chords

Evolución multi-equipo de [Mark Chords](https://markfiorente.github.io/mark-chords/) — cifrados en vivo con transposición, Modo En Vivo y Setlist, ahora pensado para que cualquier banda o iglesia tenga su propio equipo, su propio repertorio privado, y comparta entre sus propios miembros.

Este es un repositorio **separado** de `mark-chords` (que sigue siendo la app personal de Mark en producción, sin cambios). Este proyecto parte del mismo `index.html` como punto de partida y evoluciona su capa de datos hacia un backend real (Supabase) que soporta múltiples equipos independientes.

Ver el plan completo de desarrollo en las fases documentadas del proyecto (Fase 0: base de datos y seguridad · Fase 1: login y equipos · Fase 2: guardado por canción · Fase 3: migración de datos reales · Fase 4: invitaciones y equipos piloto).
